# Reviewer guide

See the [README](../../README.md) for prerequisites, startup, demo credentials, exact
test/build commands, architecture, tradeoffs and a real-time demonstration.

For UI review, browse anonymously, combine filters, change pages, open a listing and
return. Save while anonymous, authenticate or create an account, and confirm the save
and original filters/page. Compare personal watchlists in separate browser profiles.
Exercise removal, logout, empty searches and retry after a network interruption.
At 375px and 1280px, check keyboard navigation, visible focus, field labels and overflow.
